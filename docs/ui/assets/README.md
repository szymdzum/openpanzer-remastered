Material from the game itself, used only to stage the mockups. None of it is UI chrome.

- `map-ciechanow.jpg` is the Ciechanów 1939 scenario as the game draws it today, cropped from a screenshot: the hex grid, the move-range shading, the 1:1 unit sprites and the old city labels.
- `map-clean.jpg` is the top-left 1060×440 of the same map image (`map_12.png`) with nothing drawn on it, for the map layer mockup. Map pixel x,y is image x,y.
- `units-sheet.png` holds nine 80×50 frames: Pz IA, Pz IB, Pz IIA, Pz IID, Pz 35(t), Pz 38(t)A, Pz IIIE and Pz IVC from the German 1939 equipment, then the Polish 7TP. Frame i is at background-position `-80*i px 0`.
- `units-sheet2.png` is the same nine frames plus the Polish 75mm A wz.97 gun (frame 9) and 38 Piechota infantry (frame 10).
- `units-sheet3.png` is sheet 2 plus the German Infanterie (frame 11) and 10.5 leFH18 howitzer (frame 12), for the combat examples.
- `cursor-today.png` is today's attack cursor (`generateAttackCursor`) for the rugged defense case, redrawn from the game's own crosshair, flags and font at 6x, for comparison.
- `startmenu-1.jpg` is the game's own start-menu photograph (Omaha Beach, 6 June 1944, US Coast Guard, public domain). The start menu shows it in greyscale under `photo-tint`.
- `map-ciechanow-full.jpg` is the whole Ciechanów map image (`map_12.png`, 1632×1577) as JPEG, for the scenes drawn on real hex geometry (Deployment, TurnStart, AirLayer, StrategicMap, MovePath, ZoomLevels, UnitContext). Map pixel x,y is image x,y.
- `units1939.png` holds ten 80×50 frames from the Ciechanów scenario's own units: Infanterie, Psw 231(8), 15 sFH18, Me-109E-3, Ju-87B-1, PZL.23B Karas, 39 Kawaleria, 38 Piechota, 75mm A wz.97 and Pz IIIE.
