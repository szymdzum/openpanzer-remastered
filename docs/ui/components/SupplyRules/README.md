A reference table of where supply and reinforcement are worth doing, for the help pages and the handoff. It shows the divisors from `getResupplyValue` and `getReinforceValue` with real numbers for one tank: a Pz IIIE at 6/10, ammo 5/14 and fuel 20/47, at 28 prestige a point. Every value was measured with the engine.

- City with no enemy next to it: everything. Outside a city: ÷1.3. Next to 1–2 enemies: ÷1.5. Next to 3 or more: ÷3. The divisors multiply.
- Aircraft next to an airfield, and ships out of port, get everything.
- Each value is rounded. Ammo and fuel never go below 1, and that floor wrongly applies even when nothing is missing (#95).

The same breakdown appears in the context menu's tooltip for the unit at hand.
