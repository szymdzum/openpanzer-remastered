The final screen of a campaign, in its victory and defeat versions. It reuses the dossier window with a large stamp, which is `ok` for victory and `critical` for defeat. Under the stamp are the closing order, the campaign totals and the medals.

- The stamp names the result in words ("Mission accomplished", "Relieved of command"). The stamp color repeats the result but never carries it alone.
- Defeat offers Load last save before Main menu.
- This uses the dossier template (`#template__dossier`) with the campaign outcome.
