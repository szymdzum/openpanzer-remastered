Choose a campaign. The list is grouped by side, with the nation mark, years, scenario count and starting prestige. The detail column has the key facts, the difficulty and the designer's description typed as an order sheet.

- The facts row shows country, scenarios, starting prestige (already adjusted for the difficulty) and the turn allowance.
- Difficulty is a segmented control, explained in one line underneath, instead of the old help icon.
- The consumer fills the list from `campaignlist`, strips its HTML, and keeps `#smCampSel`, `#smCampDesc`, `#smCampInfo`, `#smCampCountry`, `#smCampDif`, `#smCampScenarios`, `#smCampPrestige`, `#smCPlayBut`, `#smCBackBut` and `#smCFlowBut`.
