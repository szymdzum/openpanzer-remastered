The game has two ways to change scale: the Game map scale slider in Settings (1× to 3×, uiScaleMap) and the strategic map (uiToggleMapZoom). The map and the unit sprites scale with it; markers, plaques, tags and overlay lines are drawn at screen size, so they read the same at every scale.
