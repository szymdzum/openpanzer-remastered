# The old UI (Panzer Marshal 3.2.14), reference for the redesign

The new design is in [docs/ui/](../ui/README.md); these screenshots show what it replaced. The old UI was
deleted when the new one became the game's UI (D8, #351).

Screenshots of the game as it was before the switch, taken on the Vite dev server in headless Chrome:
1920x1080, except 22-23 at iPad size (1024x768). 05 is from the tutorial, 07-21 from
Panzer-Verbaende Ostpreussen, played as Germany against the AI.

| File | Screen |
|------|--------|
| 01-start-menu | Start menu: logo, New Game, Settings, Save / Load, Continue Game |
| 02-new-game-panel | New game: campaign or scenario |
| 03-campaign-select | Campaign selection: description, country, difficulty, scenarios, prestige |
| 04-scenario-select | Scenario selection: description, sides, human/AI toggles |
| 05-settings | Settings window over the map |
| 06-save-load | Save / load: disk and cloud |
| 07-briefing-message | Scenario briefing (message dialog) |
| 08-ingame-hud | In-game HUD: status bar, right menu, map with fog of war |
| 09-unit-selected-move-range | Selected tank and its movement range |
| 10-unit-context-menu | Selected infantry with its context button (mount) |
| 11-unit-info | Unit info bar at the bottom (stats as icons) |
| 12-equipment-window | Equipment window: units on map, class filter, purchasable units |
| 13-equipment-unit-picked | Equipment window with a unit and its transports listed, buy/sell prices |
| 14-strategic-map | Strategic (zoomed out) map |
| 15-air-mode | Air layer mode |
| 16-unit-list-endturn-tooltip | Unit list strip, "Tap twice to confirm End Turn" tooltip |
| 17-ai-turn | Computer turn in progress |
| 18-turn-summary-combat-log | Turn start header: objectives, score, prestige, weather |
| 19-turn-summary-expanded | Full turn summary: combat, objectives, resupply, reinforcements, leaders |
| 20-attack-target-hover | Attacker selected, target hex marked red (no odds preview yet) |
| 21-combat-result-losses | Combat result: losses shown over the hexes |
| 22-tablet-1024-hud | HUD at iPad landscape size |
| 23-tablet-1024-equipment | Equipment window at iPad landscape size |

Not captured: the campaign dossier (end-of-scenario medals and campaign victory or defeat),
which needs a played-through campaign scenario.
